# Writing

## Styleguide

- Use short to medium length sentences.
- Use clear, plain language as much as possible, at least for concepts beyond the scope of the current piece.
- Provide definitions for more abstract, complex or technical language the reader is unlikely to be familiar with.
- Avoid hyphenation where possible. For example: prefer "front end" rather than "front-end".
- Use figures rather than words for numerical quantities. For example: prefer "12" over "twelve".
- Capitalise last names of quoted authors for a stylish touch. For example: "Felienne HERMANS".
- Separate title from author using middle dot. For example: "The Programmer's Brain • Felienne HERMANS".
- Italicise title of authored work. For example: "_The Programmer's Brain_ • Felienne HERMANS".
