- [ ] Use straight lines where possible. Minimise number of bends and crossings.
- [ ] Keep as simple as possible, minimise unnecessary detail, noise, ornamentation, etc.
- [ ] Give elements consistent size, positioning and alignment as much as possible.<br />
  For example: Similar width and height for boxes and other shapes; Lefts and tops flush; Consistent spacing between elements; Line spacing flush.
- [ ] Use grouping and some hierarchy where helpful. Co-locate and group related items.
- [ ] Consistent font-size for similar elements.
- [ ] Consistent size of elements.
- [ ] Use colour sparingly and meaningfully.
- [ ] Use recognisable, idiomatic icons or symbols.<br />
  For example, standard cloud vendor icons for AWS, Azure, etc.
- [ ] Use numbering to communicate ordered sequences.
- [ ] Where users or actors are involved, depict them as stick-figures.<br />
  Place on the left in sequence diagrams.
- [ ] Flow the elements from left to right and top to bottom.
- [ ] Avoid or minimise overlapping elements.<br />
  Where there is some necessary overlapping, try to spatially group related elements or connecting lines for clarity.<br />
- [ ] Use appropriate colour contrast for accessibility.<br />
  [Website: Contrast and Color Accessibility | WebAIM](https://webaim.org/articles/contrast/)
